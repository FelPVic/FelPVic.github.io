Open-source repositories
kochgroup / smartdock View ↗
SMARTDock (Scoring with Machine learning and Activity for Ranking Targeted Docking) — automated end-to-end toolkit that enhances virtual screening by integrating bioactivity data (ChEMBL), molecular docking with GOLD, and ML classification models. Uses the PADIF protein–ligand interaction fingerprint to build target-specific scoring functions. Delivered as a platform-independent Docker container: requires only a ChEMBL target ID, a protein structure, and a SMILES list.
Python virtual-screening CADD machine-learning Docker
kochgroup / PADIF-wf View ↗
Python reimplementation of the PADIF (Protein per Atom Score Contributions Derived Interaction Fingerprint) workflow for benchmarking decoy selection strategies in ML-based virtual screening. Trains ML classifiers using three decoy approaches: random selection from ZINC15, dark chemical matter from HTS assays, and data augmentation from diverse docking conformations. Associated with J. Cheminform. 17, 165 (2025).
Python decoy-selection PADIF virtual-screening ML
