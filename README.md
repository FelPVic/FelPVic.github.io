## 👤 About Me
I am **Felipe Victoria-Muñoz**, a Computational Chemist and Cheminformatics researcher. My work focuses on:
* **Drug Discovery:** Virtual screening and molecular modelling.
* **Machine Learning:** Target-specific scoring functions and bioactivity prediction.
* **Software:** Development of reproducible workflows for chemical data science.

## 📁 Repository Content
This site is a single-page portfolio built with **pure HTML5 and CSS3** (no heavy frameworks), ensuring fast loading and a clean "developer-centric" aesthetic. It includes:
* **Interactive CV:** Professional experience and education.
* **Publications:** List of peer-reviewed papers with DOI links.
* **Software:** Summary of open-source tools and technical skills.
